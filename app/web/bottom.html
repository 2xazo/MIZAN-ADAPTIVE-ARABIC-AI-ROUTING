    How it works

    Four steps, every request

    1. Answer economically

      The economical model answers every request first.

    2. Read confidence

      The answer itself carries the signal, so no extra call is needed.

    3. Escalate uncertainty

      A narrow gap or invalid output goes to the stronger model.

    4. Measure the trade-off

      Cost and accuracy are reported together on held-out questions.

    Not every question needs the biggest model. MIZAN helps find the ones that do.
